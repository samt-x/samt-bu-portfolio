# SAMT-BU portfolio

One issue per pilot, product and work area in SAMT-BU. The issues are the cards on the board [SAMT-BU Overview – Portfolio](https://github.com/orgs/samt-x/projects/13).

The tasks themselves live in each work area's own repository and project board. This repository holds only the portfolio cards, and is left out of the aggregate board [SAMT-BU Overview – All tasks](https://github.com/orgs/samt-x/projects/12).

What the portfolio is and how it is governed: [Oppgaver og oppfølging](https://docs.samt-bu.no/prosjektstyring/oppgaver-og-oppfolging/) on docs.samt-bu.no. How the board is set up: [Oppgavestyring](https://docs.samt-bu.no/prosjektleveranser/loesninger/samhandlingsplattform/oppgavestyring/).
